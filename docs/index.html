Climate Calculations for Japan

日本語はこちら（JP）

This documentation explains how to process climate variables using the Japan Meteorological Agency’s Mesh Climatology 2020.

The FAO-56 ET0 chapter adds a separate workflow for NARO daily inputs from 2008–2018, alongside the existing Thornthwaite PET workflow based on 1991–2020 JMA/MLIT monthly normals. Reference ET0 and temperature-based PET have different definitions, inputs and periods. The new chapter executes synthetic examples only; permission to share the NARO-derived ET0 and precipitation tables or maps remains unconfirmed.

This documentation explains how to process climate variables using the Japan Meteorological Agency's [Mesh Climatology 2020](https://www.data.jma.go.jp/stats/etrn/view/atlas.html).

The [FAO-56 ET0 chapter](notebooks/calculate_ET0.qmd) adds a separate workflow
for NARO daily inputs from 2008–2018, alongside the existing Thornthwaite PET
workflow based on 1991–2020 JMA/MLIT monthly normals. Reference ET0 and
temperature-based PET have different definitions, inputs and periods.
The new chapter executes synthetic examples only; permission to share the
NARO-derived ET0 and precipitation tables or maps remains unconfirmed.

## About the data

::: {.callout-note}
For an overview of Mesh Climatology 2020, see the [JMA press release](https://www.jma.go.jp/jma/press/2204/04a/mesh2020.html).
:::

This project uses the National Land Numerical Information (MLIT) [Average Value Mesh Data](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-G02-v3_0.html).

This repository does not redistribute original or processed datasets. Please download required data on your own.

Please review the [NLNI terms of use](https://nlftp.mlit.go.jp/ksj/other/agreement.html), especially the source attribution requirement.

## Package management

This repository uses [renv](https://rstudio.github.io/renv/) for R package dependency management.
After cloning, run `renv::restore()` to reproduce the package environment.

If you do not use renv, install required packages manually.

このドキュメントでは、気象庁の[メッシュ平年値2020](https://www.data.jma.go.jp/stats/etrn/view/atlas.html)を用いて、気候変数を処理する方法を説明します。

NAROの2008〜2018年の日別データを用いる[FAO-56 ET₀章](notebooks/calculate_ET0.qmd)を追加しました。従来のThornthwaite法によるPETはJMA・国土交通省の1991〜2020年の月別平年値を用います。両者は物理量の定義、入力、期間が異なります。ET₀章は架空データだけで実行し、NARO派生表・地図の外部共有可否は未確認です。

## データについて

::: {.callout-note}
メッシュ平年値2020の概要については、[気象庁の報道発表資料](https://www.jma.go.jp/jma/press/2204/04a/mesh2020.html)を参照してください。
:::

データは、国土数値情報の[平均値メッシュデータ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-G02-v3_0.html)を使用します。

元データや加工データについてはこのリポジトリでは配布いたしません。
必要なデータは、ご自身でダウンロードいただくようお願いいたします。

利用規約については、[国土数値情報の利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html)をご確認ください。
特に、**出典の明記**を忘れないようにお願いいたします。

## パッケージ管理について

本リポジトリでは、Rのパッケージ管理に[renv](https://rstudio.github.io/renv/)を使用しています。
リポジトリをクローンした場合、`renv::restore()`を実行することで、本リポジトリの環境を再現できます。

もしrenvを使用しない場合、適宜必要なパッケージをインストールしてください。
